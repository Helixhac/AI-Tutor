AI Tutor — Kənar sayta iframe ilə inteqrasiya nümunəsi

Bu səhifə, AI Tutor widget-inin başqa bir veb sayta necə <iframe> vasitəsilə inteqrasiya oluna biləcəyini göstərir — məsələn bir LMS (Learning Management System) və ya kurs platforması daxilində.

Canlı nümunə

İnteqrasiya kodu

<iframe
  src="https://sənin-domenin.com/embed/{material_id}?pages={pages_count}"
  width="480"
  height="640"
  style="border:1px solid #e2e2e2; border-radius:12px;"
  title="AI Tutor Widget"
></iframe>

material_id — /api/materials/upload/ endpoint-inin qaytardığı ID. pages — həmin sorğunun pages_count sahəsi.

Responsive hündürlük (postMessage)

Widget, məzmunu dəyişəndə valideyn səhifəyə postMessage ilə öz hündürlüyünü bildirir. Valideyn sayt bunu dinləyib iframe-in hündürlüyünü avtomatik tənzimləyə bilər: 

window.addEventListener("message", (event) => {
  if (event.data?.type === "ai-tutor-resize") {
    document.getElementById("ai-tutor-frame").style.height =
      event.data.height + "px";
  }
});
